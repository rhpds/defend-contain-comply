# Module 03: COMPLY -- Audit, Harden, Deliver

### Brief Overview

This module completes the vulnerability response lifecycle by establishing auditable compliance. Participants run a pre-hardening audit against 13 OPA compliance controls, apply CIS benchmark hardening to RHEL systems, re-audit to confirm remediation, and generate HTML compliance reports. The module then shifts to container security: participants build a hardened container image from UBI9-minimal, scan it with oscap-podman, push it to a local registry, and run a full compliance AAP workflow that combines system-level and container-level checks into a single automated pipeline.

### Audience and Time

- **Target personas:** Security engineers, compliance officers, platform engineers responsible for audit evidence
- **Prerequisites for this module:** Completion of Module 01 (DEFEND) and Module 02 (CONTAIN), familiarity with compliance concepts and container basics
- **Estimated duration:** 45 minutes

### Learning Objectives

- Deploy a compliance audit pipeline that evaluates systems against 13 OPA controls and generates HTML compliance reports
- Implement CIS benchmark hardening on RHEL systems and verify remediation through re-audit
- Build hardened container images from UBI9-minimal, scan them with oscap-podman, and push them to a local registry
- Automate a full compliance AAP workflow that combines system and container compliance checks

### Detailed Steps

1. In AAP Controller, launch the compliance audit job template that evaluates rhel01 and rhel02 against 13 OPA compliance controls covering password policy, SSH configuration, firewall rules, audit logging, and more.
2. Review the audit output in AAP. Identify which controls pass and which fail on each host.
3. Navigate to the compliance portal on the central node to view the pre-hardening audit results in the HTML report.
4. Run the CIS hardening playbook from AAP against both application servers. The playbook applies CIS Level 1 benchmarks including password complexity, SSH hardening, audit daemon configuration, and filesystem permissions.
5. Re-run the compliance audit job template. Verify that previously failing controls now pass.
6. Generate updated HTML compliance reports and compare pre- and post-hardening results on the compliance portal.
7. SSH to rhel01. Build a hardened container image using a Containerfile based on UBI9-minimal that applies security best practices (non-root user, minimal packages, read-only filesystem).
8. Run oscap-podman to scan the built container image against the applicable SCAP profile. Review the scan output for any findings.
9. Tag and push the scanned container image to the local container registry on the central node.
10. In AAP Controller, run the full compliance workflow that orchestrates: system-level OPA audit, CIS compliance verification, container build, container scan, and registry push in a single automated pipeline.
11. Review the workflow results, confirming all nodes completed successfully and compliance evidence is available on the portal.

### Key Takeaways

- OPA compliance controls provide a declarative, auditable framework for evaluating system security posture
- CIS benchmark hardening applied via Ansible delivers repeatable, consistent security baselines across fleet
- Hardened container images built from UBI9-minimal with OpenSCAP scanning extend compliance to the container supply chain
- A single AAP workflow can unify system-level and container-level compliance into one automated, auditable pipeline
- HTML compliance reports provide stakeholder-ready evidence for audit and governance requirements

### Infrastructure Notes

- The 13 OPA compliance controls are pre-loaded on the OPA server on the central node
- CIS hardening playbook targets RHEL 9.x CIS Level 1 benchmarks
- UBI9-minimal base image is pulled from registry.access.redhat.com
- The local container registry runs on the central node
- oscap-podman requires the OpenSCAP SCAP content package installed on the host
- The compliance portal on the central node renders HTML reports generated by the audit playbooks
